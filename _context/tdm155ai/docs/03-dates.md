# Dates

The camera as an optical instrument runs from antiquity to now. Chemical recording inside it lasted about 175 years. The bare digital sensor at the image plane is about 25 years old. For most of the camera's life the thing at the image plane was a screen and the thing recording was a hand.

| Date | What |
| --- | --- |
| c. 400 BCE | Mozi describes the pinhole image |
| c. 1020 | Ibn al-Haytham, *Book of Optics*: light in straight lines, the image inverted |
| 1088 | Shen Kuo describes the inversion |
| 1435 | Alberti, *De pictura*: the veil for perspective drawing |
| c. 1490 | Leonardo describes the camera obscura and compares it to the eye |
| 1545 | Gemma Frisius: the first published picture of a camera obscura (an eclipse) |
| 1550 | Cardano puts a lens in the hole |
| 1568 | Barbaro adds a stop to sharpen the image and recommends it for drawing |
| 1604 | Kepler coins *camera obscura* |
| 1646 | Kircher's walk-in cube with an artist inside |
| 1685 | Zahn's reflex box: a camera with no film |
| 1720s–60s | Canaletto and Reynolds draw with cameras |
| 1806 | Camera lucida |
| 1826/27 | Niépce: the earliest surviving camera photograph |
| 1835 | Talbot's *Latticed Window*, the earliest surviving negative |
| 1839 | Daguerreotype announced; Herschel coins "photography" |
| 1840 | Petzval's fast portrait lens (its swirl is now a look) |
| 1844–46 | Talbot, *The Pencil of Nature* |
| 1857–58 | Combination printing: compositing is as old as the medium |
| 1900 | Kodak Brownie: "You press the button, we do the rest" |
| 1904 | Scheimpflug patents the tilted plane of focus |
| 1925 | Leica: 35 mm, fast and small |
| 1941 | *Citizen Kane*: deep focus as storytelling |
| 1948 | Polaroid; Shannon's "noise"; Wiener's "feedback" |
| 1969 | The CCD sensor; Lucier, *I Am Sitting in a Room* |
| 1974 | Paik, *TV Buddha*: a statue watches its own live feed |
| 1975 | Sasson's first digital camera; *Barry Lyndon* by candlelight |
| 1990 | Photoshop 1.0 |
| 1991 | Morell turns rooms into cameras obscura |
| 2007 | The iPhone |
| c. 2016 | Computational photography: the phone interprets before you touch the file |
| 2020–22 | Diffusion models: images that start from noise |
